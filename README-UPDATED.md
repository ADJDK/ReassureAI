# ReassureAI frontend update

This update implements the approved ReassureAI workspace design:
- Compact left sidebar with five presets and message-count slider.
- Main writing area with 2x2 message-format cards and 2x2 capitalization cards.
- Right-side Customise drawer with tone, length, emoji, writing style, language, and additional preferences.
- Minimal emoji use and no slogan/footer clutter.

## Run locally
1. Extract the ZIP.
2. Open a terminal in `frontend`.
3. Run `npm install` if needed.
4. Run `npm run dev`.

Note: The uploaded ZIP contained frontend files only. The Generate button currently shows a clear frontend-only notice; real AI message generation needs to be connected to the project's backend/API in a follow-up step. No backend was changed.
